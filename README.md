# 海外云服务器推荐：先搞清机房和线路，再按预算判断香港、洛杉矶、东京哪台值得买

搜「海外云服务器推荐」的人，需求通常只有三种：面向国内访客建站、跑跨境业务或社媒账号、找个便宜的海外 Linux 机器跑脚本和备份。这三种需求挑出来的机器完全不是同一台，所以先别急着比价格，把下面三件事定下来，可选项会自动缩掉一大半。

## 一、先定机房位置，再谈配置

机房决定物理延迟的下限，这条改不了。你后面花的钱，大部分是在买「这个下限能不能稳定保持」。

- **面向中国大陆访客**：香港通常三网往返 40–60ms，洛杉矶 130–170ms，日本东京介于两者之间。香港离得近，但同配置在香港普遍贵，而且带宽小——常见 1Gbps 端口配几百 GB 月流量。
- **用户主要在北美或欧洲**：选洛杉矶、圣何塞、法兰克福这类节点，别为了「国内访问快」把主站放在离用户最远的地方。
- **做 TikTok、跨境电商、多账号运营**：IP 归属地和 IP 类型比延迟更重要。这类需求要确认的是原生 IP、ASN 类型、DNS 区域这些属性，不是带宽数字。
- **只要一台便宜机器跑监控、探针、备份、Docker 小服务**：国际线路的年付套餐就够了，不用为 CN2 付费。

一个常见误区是把「延迟低」当成唯一指标。实际体感更受晚高峰丢包和路由波动影响。买之前拿商家公开的测试 IP 或 Looking Glass，在你本地运营商、晚上八到十一点这个时间段各 ping 一遍，比看任何评测都准。

## 二、线路名词速查

广告页上的「高速直连」「精品线路」基本都能翻译成下面几个词：

| 线路代号 | 大致是什么 | 适合谁 |
| --- | --- | --- |
| CN2 GIA（AS4809） | 电信最贵的跨境产品，双向质量都控制得比较严 | 电信用户为主、对稳定性要求高 |
| CMIN2 | 移动的精品跨境线路 | 移动用户为主，或三网混合但要均衡 |
| AS9929 | 联通精品网 | 联通用户为主 |
| 国际 BGP | 普通国际互联，不做中国方向优化 | 用户在海外的业务、备用机 |

注意一点：线路名称只是初筛条件。同样是「三网 CN2 GIA」，不同商家给的带宽、超量策略、是否超售差得很远，甚至同一家不同机房也不同。所以看到线路标签之后，还要看它流量用完怎么处理。

**流量超额策略**是很多人下单前会忽略的地方。有的商家直接停机或按 GB 收超量费，账单能翻好几倍；有的降速继续跑。后者对使用量偶尔超出的用户友好得多。

## 三、这家为什么常被拿来当参照

在华人圈的海外 VPS 讨论里，DMIT 被反复提到的原因是它的产品分层足够清楚：一间机房、三条线路、几个硬件平台，价格和用途一一对应，不需要看一堆形容词。

它是 2017 年前后成立的美国注册商家，机房覆盖洛杉矶（LAX）、香港（HKG）、东京（TYO），全系 KVM 虚拟化，付款支持支付宝、微信支付、PayPal 和信用卡。产品按线路分三档：

- **Pro（Premium）**：三网回程走 CN2 GIA，电信去程 AS4809、联通去程 AS4837、移动去程经香港移动，是它对大陆访问最贵的线路档位。
- **EB（Eyeball）**：回程走 CMIN2 和 AS9929，同价位下给的月流量比 Pro 更大，偏流量型。
- **T1（Tier 1）**：国际 BGP，不做中国方向优化，胜在便宜、端口大、流量多。

硬件平台分 AS3（AMD EPYC 7003）、AN4（EPYC 9004）、AN5（EPYC 9005）三代。同一档位换到更新的平台，价格会往上走一截——目前官网最低配的 AN5 Pro 就已经从月付改成了季付 $37.99 起，而老平台 AS3 同配置还停在 $10.90/月。库存和平台同时在变，这也是它的套餐价格在不同文章里对不上的原因。

需要提前说明一个官方自己承认的点：**LAX AS3 平台目前仍标注为持续优化阶段，磁盘性能和服务等级可能低于成熟平台**。要跑正式业务的话，建议先买最短周期实测，别一上来就上三年。

## 五、按场景选，比按价格选更靠谱

**面向国内访客的个人博客或企业站**
先看 LAX.AS3.Pro.TINY 或 EB.TINY，$10.90/月、20GB SSD、1TB 流量，跑系统加静态站和一般 CMS 够用。真不够再加配置，比一开始买大套餐划算。移动用户占比高就选 EB，电信为主选 Pro。

**访问量已经上来、月流量超 5TB**
看 LAX.AS3.EB.MINI 或 STARTER。同价位的 EB 比 Pro 多一倍流量，回程走 CMIN2 和 AS9929，移动和联通体验更好，电信在高峰期会比纯 GIA 稍逊。

**对大陆延迟最敏感**
香港 Pro，接受它贵和流量小的事实。1核 1G 就要 $39.9/月，这个价格在洛杉矶能买到 6 核 8G。

**TikTok、跨境直播、多账号**
重点不是带宽，是 IP 属性。洛杉矶 Pro 提供原生美国 IP，部分流媒体和平台可用性较好，但这不是永久保证——平台风控、IP 库更新都会影响结果，下单后要立刻自己验一遍。DMIT 结算时有个「IP Guarantee+」选项，含义是分到的 IP 若在敏感地区不可用，可以提工单免费换一个。

**便宜、跑得久、不追求回国速度**
T1 系列，年付 $36.9 起，或者 T1.MINI 的 $12.90/月。这个预算放在国内商家那边基本只能买到小带宽限流量的机器。

**要长期跑、怕被攻击或超量关机**
AS3 的 Pro / EB 全系都是超量降速不停机，限速从 4Mbps 到 10Mbps。这是它相对便宜商家的实际差别：便宜机器往往直接停机或者超量另计费。

## 六、价格和优惠怎么读

DMIT 的定价逻辑是「周期越长单价越低」，年付通常比月付便宜一截，部分产品是官网自动折算的，不需要手动填码。除此之外它会不定期放出循环折扣码，网上流传过的类型大致是这几类：

- LAX EB 非月付周期折扣，针对入门以上的档位；
- 洛杉矶 Pro / EB 的年付折扣，STARTER 及以上力度更大；
- 东京、香港 T1 的季付及以上折扣；
- 香港 / 东京 Pro 季付及以上的循环折扣。

这类码有前缀和时效，几个月前的码大概率已经失效。**正确用法是在结算页选好套餐和周期后，把码填进输入框点一下验证按钮**，能减就直接减，报错就说明过期了，别把折扣当成下单理由。年付自动折扣叠加优惠码的情况，结算页会分别显示。

顺便提醒一句：年付确实便宜，但别拿三年期的价格做决策依据。DMIT 的库存和产品线变动很快——洛杉矶 AN4 全线下架、AN5 重新上架后入门价涨了约 2.7 美元/月、香港 Eyeball 直接停产，这些都是过去几个月内发生过的事。先用季付或半年付试运行一段，确认满意再续长周期，风险小得多。

## 七、下单前检查清单

1. 用测试 IP 或 Looking Glass，在你自己的网络、晚高峰时段实测延迟和丢包。
2. 看清月流量是单向还是双向计费，超量后是停机、收费还是降速。
3. 确认 IPv4 是否独享、有没有给 IPv6 /64。
4. 确认端口带宽是独享还是共享——10Gbps 端口不等于你单线程能跑满。
5. 读一遍退款条款和续费价格，很多低价套餐只是首期便宜。
6. 在最短周期内跑一遍 I/O 和 CPU 基准，有问题趁还没大规模部署时处理。
7. 重要数据永远做异地备份，「不超售、在线率高」和数据不丢是两回事。

## 常见问题

**Q：洛杉矶和香港到底选哪个？**
看你的访客在哪。访客主要在国内、预算够，香港延迟更低；预算有限或者访客在海外，洛杉矶同价格能买到好几倍的配置和流量。纠结的话，先在洛杉矶买一台 $10.90/月 的 AS3 TINY 实测你的运营商到美西是什么水平，再决定要不要为香港的低延迟额外付费。

**Q：Pro 和 EB 差在哪，值得多花钱吗？**
两者同价位，不是贵贱关系。Pro 回程走 CN2 GIA，电信体验更稳；EB 回程走 CMIN2 和 AS9929，流量给得多。用电信为主、对抖动敏感选 Pro；移动联通为主或流量吃紧选 EB。

**Q：T1 是不是不能往国内用？**
能用，只是不优化。晚高峰延迟和丢包会比 Pro、EB 明显，适合国际业务、落地和自建中转，不适合作为面向国内访客的主站入口。

**Q：超流量真的不会关机吗？**
AS3 的 Pro / EB 系列以及 T1 系列都是超量限速继续运行，限速值随档位变化（Pro / EB 从 4Mbps 起，T1 的 WEE 在洛杉矶为 100Mbps、香港和东京为 50Mbps）。这条规则提高了可用性下限，代价是限速期间几乎跑不动大流量传输。

**Q：支持什么付款方式？**
支付宝、微信支付、PayPal 和信用卡，对国内用户来说不需要额外准备外币卡。

海外云服务器选到最后，比的从来不是单个参数，而是「你的实际场景」和「这台机器的定位」是否对得上。先把机房和线路定死，再用最短周期实测一轮，比看十篇评测都管用。
